## Architecture

**Next.js 15 App Router, React 19, all components client-rendered (`'use client'`).**

- `app/layout.jsx` — Root layout; imports `globals.css`
- `app/page.jsx` — Assembles the full page: `DiscoIntro` → `SvgSymbols` → `SmoothScroll` → `CursorBubble` → `Navbar` → `VimeoHero` → `HorizontalWords` → `MotionCards` → `Showreel` → `ServiceCards` → `DoubleMarquee` → `Footer` → `TransitionScribble`
- `app/styles/` — 11 vanilla CSS partials (no Tailwind), imported via `globals.css`; CSS variables define the colour palette
- `lib/data.js` — Single source of truth for all static data: `brands`, `colors`, `SOCIAL_ICONS`, `CARDS_DATA`, `WIGGLE_CONFIG`, `ANIMATION_CONFIG`, `FAQ_DATA`
- `components/SvgSymbols.jsx` — Hidden `<symbol>` defs (`bullet-icon`, `card-divider`) used via `<use>` across the app

## Animation System

- **GSAP** (`gsap`, `ScrollTrigger`, `InertiaPlugin`) powers every interaction
- **Lenis** handles smooth scrolling, synced to GSAP's ticker in `SmoothScroll.jsx`; stored on `window.__lenis` for other components
- `DiscoIntro.jsx` — Three.js disco-ball loader that plays before the site renders
- `CursorBubble.jsx` — GSAP `quickTo` tracked blob with context-aware text
- `TransitionScribble.jsx` — Full-screen scribble mask triggered by logo click; auto-runs on load

## Data-Driven Components

- `ServiceCards` reads `CARDS_DATA` from `lib/data.js`; stickers/services are generated by mapping over it
- `DoubleMarquee` uses `brands` + `colors` with `shuffleNoAdjacentSrc` / `assignColorsNoAdjacent` to avoid adjacent duplicates (including the loop seam)
- `WIGGLE_CONFIG` in `lib/data.js` controls all hover-wiggle intensities in one place

## SVG Strategy

| Strategy | Where |
|---|---|
| External `.svg` via `<img>` | Brand logos, stickers, blobs |
| `<symbol>` + `<use>` | Repeated icons (`bullet-icon`, `card-divider`) |
| Inline `<svg>` | Animated paths needing `stroke-dasharray` |
